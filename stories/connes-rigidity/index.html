Different groups, the same mathematical object

Could different mathematical systems look identical through the same lens? OpenAI reports that Astra constructed infinitely many different groups with the same operator algebra, challenging a conjecture about what that algebra can reveal.

By Sander Knape

Draft preview · Not yet published/5 min read

When are two groups the same?

Think of turning a square: a quarter-turn followed by another quarter-turn is a half-turn. Combining turns follows a fixed rule.

Calling a quarter-turn “A” instead of “B” changes nothing about what the turns do. For two groups to be genuinely different, no relabelling can make all their combination rules match.

A mathematical group describes things you can compose: rotations, for example, where one turn followed by another produces a third. Its defining feature is the rule for combining its elements. Could you recover that rule from another mathematical object built from it?

OpenAI reports that its Astra AI system constructed infinitely many genuinely different groups whose associated operator algebras are indistinguishable. The construction challenges a general reconstruction conjecture associated with Alain Connes. OpenAI credits Astra with generating the mathematical argument, and people with helping prepare the manuscript and formalize proofs for computer checking.

To build a group’s operator algebra, mathematicians start with functions that assign values to its elements. Each group element supplies an operation that shifts those values according to the composition rule. These operations generate a larger algebra. Reconstruction asks whether that algebra determines the original group, allowing for renamed elements.

Astra’s reported answer is no - even under specific conditions intended to impose considerable rigidity.

Changing the groups without breaking the conditions

Simply finding different groups with matching algebras would not settle this conjecture. The groups must satisfy two demanding conditions, called ICC and property (T).

ICC requires every nonidentity element to have infinitely many conjugates: versions produced by the group’s internal symmetries. It ensures that the associated algebra is a factor, a particular kind of operator algebra. Property (T) imposes a separate rigidity requirement on the group’s possible actions by transformations. It must hold for each completed group, so preserving it constrains how the construction can introduce a difference.

Those requirements blocked an initially promising route. According to OpenAI’s retrospective reasoning account, the approach began with different finite groups that already had matching complex group algebras. But placing a nontrivial finite normal subgroup inside the construction broke ICC: some elements could have only finitely many conjugates. Spreading the finite difference across many coordinates instead lost property (T).

The account describes a consequential change of target: construct different group laws on auxiliary spaces while preserving their probabilities and the transformations acting on them. This is a model-reconstructed account based on reasoning records and papers, rather than an independently observed discovery log.

A difference made by carrying a bit

How can the same states and probabilities support different rules for combining them? Start with the manuscript’s four-state example.

Take two bits, giving four states: 00, 01, 10 and 11. One composition rule adds each bit separately, wrapping back to zero and never carrying. Combine any nonzero state with itself and you return to 00.

Another rule treats the states as the numbers zero through three, adding with a carry and wrapping around after three. Now repeatedly adding 01 takes four steps to return to 00.

The states can have exactly the same probabilities under both rules. Yet no renaming makes the rules identical: a two-step return cannot become a four-step return merely by changing labels.

This is an illustration, not the counterexample. The infinite construction has to preserve much more than four equally weighted points.

Astra’s reported argument extends the carry idea to infinite auxiliary spaces. It introduces coordinates that accommodate the products of bits created by carrying, while ensuring that the revised law preserves probability and remains compatible with an acting group’s transformations. Compatibility means that identifying the two spaces also matches the transformations on each side.

These auxiliary groups supply building blocks for the final countable groups; they are not themselves the groups named in the theorem. An established operator-algebra identity lets mathematicians represent each final algebra using two ingredients: functions with bounded values on the auxiliary probability space, acting by multiplication, and operators that implement the acting group’s transformations. Functions that differ only on a set of probability zero count as the same. Matching the spaces while preserving probability therefore matches the function part; matching the transformations also matches how the added operators interact with those functions. Together, these matches identify the algebras without requiring the auxiliary composition laws to match.

The proof must then keep the difference visible in the final groups. It chooses an acting group with no nonidentity finite-order elements, so that component cannot introduce a misleading four-step cycle. One final group has elements requiring four repetitions to return to the identity; the other does not.

From one counterexample to infinitely many

A pair defeats uniqueness. Producing an infinite family requires another distinction.

The construction shifts where the carry begins, creating successive candidates with the same operator algebra. All these candidates have four-step elements, so the earlier test cannot distinguish them from one another. The proof instead uses a count defined by the group’s own structure, preserved under any relabelling. That count changes with the shift.

Alongside this, the manuscript establishes ICC and property (T). The resulting groups are also finitely generated: finitely many starting elements, combined and inverted, produce every element, although the groups themselves are infinite.

The result remains a reported construction, not an independently validated theorem in this article. OpenAI has released a formal certificate, but the reporting here did not replay it or independently establish that its definitions and conclusion fully match the intended mathematics. Public objections also exist; a limited response challenges one argument without validating the whole construction. This account does not adjudicate that dispute.

Zhou’s separate concurrent work, also developed with substantial AI assistance, supplies a different counterexample - not replication of Astra’s certificate or grounds for exclusive priority. Separate reconstruction questions about higher-rank lattices, a more specific class of groups, remain outside this result.

The manuscript cites an existing bound: at most countably many group types satisfying these conditions can share one factor. Astra’s reported family reaches that bound. This counts different possible groups, not elements within a group. Even narrowing the answer to a finite list would be impossible for this factor: the alternatives continue indefinitely.
