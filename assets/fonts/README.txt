# Local fonts

These unmodified TrueType files were downloaded from Google Fonts on September 25, 2026, for the approved website typography. `fonts.css` serves them from this site with `font-display: swap`; no browser request goes to Google.

- Barlow Semi Condensed, normal weights 400, 500, 600, 700, and 800: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed). See `barlowsemicondensed-OFL.txt`.
- Source Serif 4, normal weights 400 and 600: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/sourceserif4). See `sourceserif4-OFL.txt`.

Preserve the license files when redistributing the fonts. Font files are static assets; changing typography does not require a JavaScript package or font service.
